# ЕГЭ по Мелстрою

Веб-приложение в формате «угадай фразу по картинке». 79 картинок Мелстроя без зелёного фона; в каждом тесте показывается случайные 50 из них, у каждой 4 варианта подписи, балльная система и история игр.

Если у двух файлов одинаковое имя, отличающееся только хвостовым числом (например `аааааа.png` и `аааааа2.png`), они считаются одним и тем же ответом «аааааа» — обе картинки правильно угадываются по этой подписи, и в одном вопросе такая подпись не появляется дважды среди вариантов.

## Открыть

Через GitHub Pages: <https://yarospr.github.io/mellege/>

Локально — открыть `index.html` в браузере (для корректной работы лучше из локального сервера, например `python3 -m http.server`).

## Структура

- `index.html`, `styles.css`, `app.js`, `data.js` — само приложение.
- `images/` — обработанные картинки без зелёного фона.
- `*.png` в корне — исходные картинки с зелёным фоном.
- `scripts/remove_green.py` — скрипт для удаления зелёного хромакея.

## Пересобрать картинки без фона

```bash
pip install --user numpy Pillow
python3 scripts/remove_green.py
```

## Подсчёт баллов

- Правильный ответ за ≤ 3 секунд — 2 балла.
- Дольше: `2 − (t − 3) / 10`, но не меньше 1 балла.
- Неправильный ответ — 0 баллов.
- Итог округляется до целого, максимум 100.
